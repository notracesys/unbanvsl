# **App Name**: AprovaçãoDrive

## Core Features:

- Exploração de Conteúdo em Árvore: Visualização interativa das pastas de arquivos simulando a organização premium do Google Drive para facilitar a navegação.
- Smart Tutor Tool: Ferramenta movida por IA que utiliza inteligência generativa para analisar seu desempenho em simulados e sugerir quais pastas do drive focar.
- Dashboard de Visualização Glassmorphism: Interface moderna com efeito de vidro fosco para exibir os diferenciais e benefícios dos materiais de estudo.
- Matriz Comparativa Interativa: Componente visual que demonstra as vantagens de estudar com material organizado versus o caos de arquivos espalhados.
- Seção de Prova Social Animada: Cards flutuantes com depoimentos ilustrativos para construir autoridade e confiança visual imediata.
- Central de FAQ com Accordions: Área de dúvidas frequentes com animações suaves de abertura para melhorar a experiência do usuário e conversão.
- Gerador de Resumos Automático: Uma funcionalidade experimental que permite gerar um resumo rápido de qualquer título de pasta usando IA antes mesmo do acesso.

## Style Guidelines:

- Cor primária: Azul Profissional (#4285F4), escolhido por evocar autoridade e confiança. Fundo: Azul acinzentado ultra claro (#F5F9FF) para uma estética clean e premium.
- Cor de destaque (CTA): Verde de Conversão (#34A853) para botões de ação e indicações de sucesso.
- Destaque secundário: Amarelo Foco (#FBBC05) usado com moderação em badges e selos de acesso imediato.
- Para os títulos, utilizaremos 'Poppins' (Sans-serif) para uma aparência geométrica contemporânea. Para o corpo de texto, 'Inter' para garantir máxima legibilidade e neutralidade moderna.
- Layout responsivo com grids flexíveis, margens generosas e uso intensivo de bordas arredondadas (min 16px) e efeitos de glassmorphism em cards de destaque.
- Ícones lineares minimalistas de peso leve para representar as matérias e categorias, seguindo o padrão de design do Google Workspace.
- Micro-interações suaves e scroll reveal animations (Framer Motion) para dar fluidez e um sentimento de tecnologia de ponta.
